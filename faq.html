Questions and answers

What is this site built with?

Plain HTML, CSS and JavaScript — no frameworks and no templates. It was built as part of CSC 216 Lab 2.

Can I use the code from this site?

Yes. It is a learning project. Ask us first if you plan to publish a copy, and keep the co-author credits in the Git history.

How do I contact the team?

Use the contact page. The form checks your input in the browser, and we will connect it to a real server later.

Does the site work without JavaScript?

Mostly. The pages, navigation and this FAQ work with JavaScript turned off. The project cards and form validation need JavaScript, and the projects page shows a short message explaining that.
